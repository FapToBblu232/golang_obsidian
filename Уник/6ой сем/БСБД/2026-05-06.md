### Семинар
Задание: обновить остаток на складе
```
Update Products
Set stock = stock - (Select sum(qty) from Sales
					where p_id = Products.p_id)
```

Если продукт не покупали, то будет null -> `1000 - null = null`

Решение:
1) Через подзапрос с exists
```
Where Exists(select 1 from sales where p_id = Products.p_id)
```
2) Функции
```
isnull(<выражение>, <значение>) - заменяет null на значение

coalesce(<выражение 1>, <выражение 2>, ..., <значение>) - первое ненулевое значение.
```

Итого
```
Update Products
Set stock = stock - coalesce((select sum(qty) feom Sales where p_id = Products.p_id), 0);
```


### Group by
Позволяет сгруппировать строки по какому-нибудь столбцу и вычислять итоги в группах. 

Что используем? Агрегатные функции:
1) avg()
2) min()
3) max()
4) sum()
5) stdev() - стандартное отклонение
6) var()
В основном, для чисел (без null), выдают null, если значения нет

7) count() - кол-во непустых ячеек. Для уникальных - distinct. Все типы данных, пустые строки не учитывает. Нет данных? - null
8) count(\*) - кол-во строк. Все типы + null. При отсутствии выдаёт арифметический ноль.

```
select <столбцы>, <функция>
from Table
where <условие>
group by столбцы
having - уловие к функции 
```

Дополнительные параметры *Rollup/Cube*, *grouping*

табличка - brand, size, sale.

```
select brand, sum(sale) as T
from Table
group by brand
having T > 20
```

*rollup* - добавляет общий итог. 
*cube* - добавляет общий итог и группы по всем столбцам.

ms:
```
select brand, size, sum(sale) as T from Table
Group by brand, size with rollup
```
pg:
```
select brand, size, sum(sale) as T from Table
group by rollup(brand, size);
```

Rollup
	```
	brand     size     T
	Foo       L        10
	Foo       M        20
	Foo       null     30
	bar       M        15
	bar       L        5 
	bar       null     20
	null      null     50
	```
Cube
	```
	Null      L        15
	Null      M        35
	```

###### grouping
В ms - добавляет новый столбец. В этом столбце 0 -значение есть в исходной таблице, 1 - нет. Нужно бля того, чтобы понять, какие `null` значащие.
```
select brand grouping(brand),
	   size, grouping(size),
	   sum(sale) as T
from Table
group by brand, size with cube
```

Rollup
	```
	brand     size     T
	Foo  0      L      0   10
	Foo  0      M      0   20
	Foo  0      null   1   30
	bar  0      M      0   15
	bar  0      L      0   5 
	bar  0      null   1   20
	null 1      null   1   50
	```
Cube
	```
	Null 1      L      0    15
	Null 1      M      0    35
	```

В pg - groupng sets - дополнительные наборы.
```
select brand, size, sum(sale) as T
from Table 
groupng by groupng sets((brand), (size), ());
```

| null  | L    | 15                      |
| null  | M    | 35                      |
|       |      | Группы по столбцу size  |
| null  | null | 50                      |
|       |      | Это общее               |

#### Получение первых строк
`Limit n`

```
select ...
from ...
group by ...
orber by ...
limit n - отрежет от итогового запроса
```

ms
```
top n [with ties - строки разделившие последнее место]
```

```
Select p_id, price
from Products
Orderby price Desc
limit 3;
```

```
select top 3 p_id, price
from Products
order by price Desc
```

```
select top 3 with ties p_id, price
from Products
order by price Desc
```

### Задачки
products - p_id, p_name, price
sales - b_id, p_id, qty
buyers - b_id, b_name
вывести трёх лучших покупателей
```
select b_name, sum(S.qty) as T
from buyers B
join sales S on S.b_id = B.b_id
join products P on P.p_id = S.p_id
group by b_name
order by 2
limit 3;
```
