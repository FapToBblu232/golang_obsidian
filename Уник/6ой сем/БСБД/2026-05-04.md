### Лекция
#### Временные объекты
MS. TempDB - все временные объекты. Пользовательские таблицы, переменные, функции,
Использование `#` - локальный временный объект в текущей бд, только в пределах нашего сеанса.
`##` - Глобальная, все сеансы.

PG
```
create temporary/temp table <name>
(column list);
```

1) В текущем сеансе
2) Удалится после данного сеанса
3) Хранится в pg_Temp_n (n - текущая сессия)
4) Имя постоянной может совпадать с временной. 

Удобно при клонировании таблиц

```
create table New_table as table tabl1;
```

```
Declare <name> <тип данных>
set <name> = знач/(select)

@ - локальная - в текущей БД
@@ - глобальная - в бд master
```

#### Типы данных
```
Create Domain my_t <- название as <системный тип> <Условие> (check (value > 0))
```

MS
```
exec sp_addtype my_t, integer [, условие]
```

PG
```
Create type my_t as integer [условие];
```
