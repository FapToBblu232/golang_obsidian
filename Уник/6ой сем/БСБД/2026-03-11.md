### Семинар 3
Select - оператор выбора записи из таблицы
```
select <сприсок выборки>
from <название таблицы>
{where <условие>}
```

```
select p.name 
from product
```

```
select * from product
```

**distinct** - только уникальные значения, без повтора

#### WHERE
1. =, >, <, <=, >=, <>
```
	   select p.name 
	   from product
	   where price > 100
```

2. like, not like, ilike - сравнение символьных символьных данных.
   like - зависит от регистра
   ilike - нет.
   Символы заменители
	1. `_` - 1 символ
	2. `%` от 0 до 255 символов
	3. `[]` - обязательный, экранирование
	4. `[^]` - удалить
```
Select * from products
where p.name like '%t_t%'
```

`[BK]%` - первый символ или b, либо k
`[B-K]%`  - первая буква от b до к

3. Логические операторы *Not*, *And*, *Or* (написаны в порядке приоритета)
4. *Between*, *Not Between*
```
Select * from products
where p.date between '01.01.2026' and '03.01.2026'
```
за 3ее число - не попадёт, т.к. в полном типе берётся время 00.00.00

5. *in*, *not in* - принадлежность списку
6. *is null*, *is not null*
   `null != null` - так как неопределённость.

7. *order by* - многоуровневая сортировка
   По умолчанию - по возрастанию
   `desc` - по убыванию. 
   Сортируются в самом конце, перед выводом на экран.
   в качестве аргументов можно использовать числа, они будут отображать номера столбцов в select'е

8. Можем что-то посчитать, переименовать столбцы
   Был пример с выводом с *as* и литералом 'скидка 20%' 


#### INSERT
Добавление записи в таблицу
```
Insert into <название таблицы(столбцы)>
Values (значение/default/null)
```

#### UPDATE
Оператор обновления записи
```
Update <таблица>
set <столбец>=значение/null/выражение, <столбец2>=...
[Where <условие>]
```

p.name = char(10)
```
update products
set p.name = ('НЕТ' + p.name)
```
Тут будет 3 + (7 остаточных).

```
update products
set p.name = (p.name + 'НЕТ')
```
Тут будет 10 + 3 = 13 - перебор. Такой update не пройдёт.
#### DELETE
Удаление строк из таблицы
```
Delete from <таблица>
[where <условия>]
```

**Все операции логируются**, даже каждая удалённая строка хранится в транзакциях.

#### TRUNCATE
Удаление всех строк по аналогии с delete. - в PG
В MS - не логирует, восстановить - нельзя.



#### Дополнительное для SELECT
Можно также использовать:
1) *CASE* выражение
```
CASE [выражение]
When <условие> Then <результат1>
else <результат2>
end
```

```
select p.name, `new price` = 
CASE 
when p.date >= '01.03.2026' then price
when price between '01.02.2026' and '01.03.2026' then price*0.8
else price*0.6
end, p.date
from products
```

2) Конкатенация двух столбцов `(lastname + lastname) as fio`
