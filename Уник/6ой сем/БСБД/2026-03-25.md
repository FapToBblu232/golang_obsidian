#### Join
- Inner Join - стандартный. Общие строки
- Outer Join
	- Left Outer Join
	- Right Outer Join
	- Full Outer Join
- Cross Join

```
Select <Список выборки: Таблица.Столбец> 
from <Таблица1>
<Тип Join> <Таблица2>
ON Таблица1.Столбец = Таблица2.Столбец or (and) <другое условие>
[where условие, которое просматривается последним]
```

#### Дополнительно JOIN
pg: Natural Join - Есть левый, есть правый. Это Inner Join, когда имена общих столбцов совпадают. Автоматически Join'ит по общим столбцам.
on табл1.столбец = табл2.столбец -> Using (столбец)

```
select b_name, p_id, qty
From Buyers Natural Join Sales;
```
```
select b_name, p_id, qty
From Buyers Join Sales
using (b_id);
```


# ***Так не делать!***
```
select b_name, p_id, qty
from Buyers, Sales
Where Buyers.b_id = Sales.b_id
```

JOIN смотрит сначала на строчку from. Значит, хватает сразу условие, по нему вытаскивает в память строки.

Этот вариант вытаскивает в память cross join, а только потом смотрит на условие.


| a   | b   |
| --- | --- |
| 1   | 1   |
| 2   | 2   |

| a   | b   |
| --- | --- |
| 1   | 1   |
| 2   | 2   |
| 3   | 3   |

```
Select *
from Табл1 join Табл2
on Табл1.a = Табл2.a
```
Выдаст все 4 столбца.

```
Select *
from Табл1 join Табл2
using(a)
```
Выдаст 3 столбца, т.к. схлопнул столбец, по которому объединял.

```
Select *
from Табл1 Natural join Табл2
```
Выдаст 2 столбца. Объединил одинаковые имена.

### Доп. инфа.
1) *UNION* (Объединение). Одинаковое количество столбцов (желательно). Отношения одинаковой степени.
*Заголовок формирует первый select*
```
select ...
from ...
UNION [ALL - оставить дубликаты строк]
select ...
from ...
```
Нужно, чтобы списки были однотипны.

2) *Intersert* (Пересечение). Отношения одинаковой степени. Его можно получить из Union и Except. Но долго, поэтому оставили.
Аналогичный синтаксис

3) *Except* (Исключение или Разность). Принадлежат первому не принадлежат второму отношению.
