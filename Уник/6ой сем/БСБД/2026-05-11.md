### ЛР2

В лабораторной работе требуется реализовать следующие запросы к базе данных:
1. Запрос с использованием объединения таблиц. 
``` sql
SELECT s.id AS show_id,
m.title AS movie_title,
h.name AS hall_name,
c.name AS cinema_name,
s.start_time,
s.base_price
FROM Show s
JOIN Hall h ON s.hall_id = h.id
JOIN Cinema c ON h.cinema_id = c.id
JOIN Movie m ON s.movie_id = m.id
ORDER BY s.start_time;
```
2. Запрос с использованием вложенного подзапроса. 
``` sql
SELECT title, release_date
FROM Movie
WHERE id NOT IN (
    SELECT DISTINCT movie_id
    FROM Show
    WHERE hall_id IN (SELECT id FROM Hall WHERE cinema_id = 2)
);
```
3. Запрос с использованием коррелированного вложенного запроса. 
``` sql
SELECT 
    m.id,
    m.title,
    (SELECT COUNT(*)
     FROM Ticket t
     WHERE EXISTS(SELECT 1 from Show s
     WHERE t.show_id = s.id and s.movie_id = m.id)
     --JOIN Show s ON t.show_id = s.id
     --WHERE s.movie_id = m.id
    ) AS tickets_sold
FROM Movie m
ORDER BY tickets_sold DESC;
```

5. Подсчет каких-либо частных итогов (количество продукции каждого вида, средняя зарплата по каждому отделу и т. д.) с Group by.
```sql
SELECT 
    c.id AS cinema_id,
    c.name AS cinema_name,
    COUNT(t.id) AS total_tickets_sold,
    AVG(t.price) AS average_ticket_price
FROM Ticket t
JOIN Show s ON t.show_id = s.id
JOIN Hall h ON s.hall_id = h.id
JOIN Cinema c ON h.cinema_id = c.id
GROUP BY c.id, c.name
ORDER BY total_tickets_sold DESC;
```
6. Создать временную таблицу с результатами запроса к базе данных, вывести на экран ее содержимое. 
``` sql
CREATE TEMP TABLE temp_monthly_revenue AS
SELECT 
    m.title,
    COUNT(t.id) AS tickets_sold,
    SUM(t.price) AS total_revenue
FROM Movie m
JOIN Show s ON m.id = s.movie_id
JOIN Ticket t ON s.id = t.show_id
-- WHERE date_trunc('month', t.sold_at) = date_trunc('month', CURRENT_DATE)
GROUP BY m.id, m.title;
```
``` sql
SELECT * FROM temp_monthly_revenue ORDER BY total_revenue DESC;
```
