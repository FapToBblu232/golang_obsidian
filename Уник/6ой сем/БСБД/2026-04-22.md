### Семинар
#### Подзапросы
*Функции всегда через подзапрос*
**Substring**(поле, N начала, кол-во, откуда)
1) **В Select**
```
Select список выборки (Select...)
from таблица (Select...) as T
where уловие (Select...)
```

Пример с продуктами
Вывести с макс ценой
```
select p.name
from products
Where price = MAX(price) - не сработает, так как сложно
```
Нужно
```
select p.name
from products
Where price = (Select MAX(price) from Products)
```

*Если не знаешь, что делать, то представь, что таблицы на листочках. Как бы ты ручками делал?*

Больше вложенность! Теперь мы хотим узнать людей, которые купили товар с максимальной ценой.
```
select b.id
from Sales
where p.id IN (select p.name
from products
Where price = (Select MAX(price) from Products))
```

*Коррелированный подзапрос* - связанный. Работает параллельно.
`Where p_id = Sales p_id`

```
select b_id
from Sales
where (select price from Products
where p_id = Sales.p_id) = (Select MAX(price) from Products))
```
По скорости, как join
```
select b_id
from Sales
Join Products
on Sales.p_id = Products.p_id
and price = (Select MAX(price) from Products)
```

*Exists (Not Exists)* - используется с корреляцией. Использовать лучше, когда сам запрос может справиться.
`Exists(Существующие данные) = True`
`Exists(НЕсуществующие данные) = False`
```
select b_id
from Sales
where EXISTS(Select <неважно_что> from Products
where p_date = '01.01.2026' and p_id = Sales.p_id)
and price = (Select MAX(price) from Products)
```

```
select b_name, (Select sum(price * qty)
	from Sales S Join Products P
	On s.p_id = P.p_id
	where b_id = Buyers.b_id) as 'Total'
from Buyers
```

2) **В Insert** - добавление строк из другой таблицы
```
insert into Табл(столбцы)
Select ...
```

```
Insert into Clients(c_id, c_name, phone)
select (substring(Name, 1, 2) || substring(Phone, 12, 5), Name, Phone
from People)
```
3) **В Delete**
```
Delete табл
Where уловие (Select)
```

Убираем продаже старых продуктов
```
Delete Sales
where p_id IN (
	Select p_id from Products 
	where p_date < '01.01.2026'
)
```

```
Delete Sales
where Exists(select <что угодно> from Products
where p_date < '01.01.2026' and p_id = Sales.p_id)
```

```
Delete Sales
where Exists(select <что угодно> from Products
where p_date < '01.01.2026' and p_id = Sales.p_id)
```

```
Delete Sales
from Sales S join Products P
on S.p_id = P.p_id and p_date < '01.01.2026'
```

```
Delete Sales
using Products P
Where Sales.p_id = P.p_id and p_date < '01.01.2026'
```

4) **В Update**
```
Update табл
set столбец = (Select ...)
Where условие (Select ...)
```

```
Update Products
set price = price * 1.2
where sup in (
	Select s_id from Suppliers
	where country = 'USAAAAAA'
)
```

```
Update Products
set price = price * 1.2
where Exists(
	select 1 from Suppliers
	where county = 'USA'
	and s_id = Products.sup
)
```

```
Update Products
set price = price * 1.2
using Suppliers S
where S.s_id = Products.sup
and country = 'USA'; 
```
