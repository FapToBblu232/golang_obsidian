### Лекция 2

Целостность бывает:
1) Доменная - целостность столбца
2) Сущностная - однозначные идентификатор
3) Ссылочная - связь между таблицами

Как обеспечивать?
1) Декларативное - описание. На стороне сервера
	1) Ограничение. Constraint.
	2) Правило. Rule.
	3) Умолчание. Default.
2) Процедурное. За счёт объектов. И на стороне клиента, и на стороне сервера.
	1) Procedure
	2) Trigger

##### Constraint
Накладывается на добавление/изменение объектов. (Insert/update)
1) Доменная
	1) Default. Only Insert
	2) Check. Проверка данных на условие
2) Сущностная
	1) Primary Key. Уникальность + Непустой
	2) Unique 
3) Ссылочная
	1) FK - Foreigh Key. Вводимы данные присутствуют в PK
	2) References - ссылка


Процедурные ограничения создают в рамках
Create Table, Alter Table
*При добавлении проверяет ограничение на уже существующие данные*
Отказывается накладывать, если не все прошли.
```
[Constraint <Имя ограничения>] <Тип Ограничения> <Параметры>
```
```
Alter table Products
Add Constraint Def_prod_date Default current_date for p_date
```

```
Alter table Products
Add Constraint Check_phone check p_phone like '+7([0-9][0-9][0-9])[0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]'
```

```
Alter table Products
Add Constraint PK_prod Primary key (p_id)
```

```
Alter table Buyers
Add Constraint Unique_prod (LastName, FirstName)
```

Ссылаться можно на столбец с ограничением PK или Unique

```
Create table Sales
(b_id int,
p_id int constraint FK_prod Foreigh key
	References Products (p_id),	
date,
....)
```

Что делать при удалении? ON Delete *(No Action - не даст менять первичный ключ, Cascade (обычно при Update), Set Null, Set Default)*
Что делать при изменении? ON Update

```
Create table Employees
(emp_id int FK,
emp_name varchar(20),
boss_id int References Employees(emp_id))
```

#### Индекс
Надстройка над таблицей. Нужно для ускорения.
PG: B-Tree и Hash, Git (Графическая), BT-GIT
MySql: Clustered, nonclustered 

Nonclustered = B-tree - Сбалансированное дерево.

При создании первичного ключа создаётся индекс. 
PK - clusetered/B-tree
Unique - Nonclustered/B-tree
FK - RowID- номер файла, номер страницы, номер строки.

То есть есть таблица. Это файл, где много столбцов.
Берём PK, сортируем их, дописываем RowID. Теперь это таблица Indexes
Строим B-tree по отсортированным.
