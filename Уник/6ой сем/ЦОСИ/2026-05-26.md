### Подготовка к Ромчику
Вопросы к блицу:  
**Часть 1.**  
1. Обучение с учителем и без учителя:
	1. С учителем - на размеченных данных. Цель - предсказать целевую переменную. Били данные на 70 на 30. Где 70 на обучение с учителем. классификация, регрессия.
	2. Без учителя - без разметки. Модель ищет скрытые закономерности, структуры или группировки. Пример: кластеризация
2. Задача регрессии (с примером)  
	1. Прогнозирование **непрерывного** числового значения. Функцию пытались предугадать. Или акции компании и мы миллионеры. Предсказание цены квартиры на основе площади, этажа, района.
3. Задача классификации
	1. Отнесение объекта к одному из дискретных классов.
	   Пример: задача о Ирисах. вот я с вероятностью 60% - лотус.
4. Задача кластеризации 
	1. Разбиение объектов на группы (кластеры) так, чтобы объекты внутри одной группы были похожи друг на друга. Лабы по ИТИБ, где были даны адреса каких-то важных мест, а нейронка давала административные центры. 
5. Линейный фильтр и его применение к изображению \
	1. Фильтр, где новое значение пикселя вычисляется как **взвешенная сумма** соседних пикселей. Здесь бы рассказать про компьютерное зрение. Примеры - делали blur, границы. 
  
**Часть 2.**  
6. Логистическая регрессия, SVM  
	1.  Модель для бинарной классификации. Оценивает вероятность принадлежности к классу с помощью сигмоидной функции.
	2. **SVM (Метод опорных векторов)**  Строит разделяющую гиперплоскость, максимизирующую отступ (зазор) между классами. Использует ядра для нелинейных данных.
7. Наивный байесовский классификатор (допущения), Accuracy, Precision, Recall, матрица ошибок
	1. **Допущения:** Все признаки условно независимы друг от друга при заданном классе.
	2. **Матрица ошибок:** Таблица, показывающая TP, TN, FP, FN.
	3. **Accuracy:** (TP+TN) / (Всего) — общая доля верных ответов.
	4. **Precision:** TP / (TP+FP) — из предсказанных положительных сколько действительно положительных.
	5. **Recall:** TP / (TP+FN) — из всех реальных положительных сколько найдено.
8. Дерево решений
	1. Модель, разбивающая данные на подмножества на основе вопросов о значениях признаков (например, "возраст < 18?"). Разбиения выбираются по критерию минимума энтропии (или Gini impurity). Интерпретируемо, но склонно к переобучению.
	2. **`max_depth`** + **`max_features`** 
9. Случайный лес
	1. Ансамбль множества деревьев решений, обученных на разных подвыборках данных (бэггинг) и случайном подмножестве признаков. Итоговый результат — голосование или среднее. Устойчив к переобучению.
10. One hot encoding, cross validation, валидация на отложенной выборке
	1. **One-hot encoding:** Преобразование категориального признака в бинарные векторы (например, "цвет": красный → [1,0,0]). Факторизация - когда признак в чиселку.
	2. **Отложенная выборка (Hold-out):** Деление данных на train (обучение) и test (контроль, для финальной оценки).
	3. **Cross validation:** Разбиение train-выборки на K частей, где модель поочередно обучается на K-1 части и валидируется на оставшейся. Позволяет надежнее оценить качество.
  
**Часть 3.**  
11. Градиентный спуск, метод обратного распространения ошибки
	1. **Градиентный спуск:** Итерационный метод оптимизации, движущий параметры в сторону, противоположную градиенту функции потерь, для ее минимизации. Оптимизатор Adam(learning spead, **`beta1`** - момент инерции, **`beta2`** - тоже, чтобы маленькие шаги при резком изменении, большие при малом изменении)
	2. **Backpropagation:** Алгоритм вычисления градиента функции потерь для каждого веса сети, используя цепное правило (от выходного слоя ко входному). Просто обратно идём. 2рк по ИТИБ.
12. Устройство нейрона, функции активации (с примерами) 
	1. **Нейрон:** Вычисляет взвешенную сумму входов (+ bias) и применяет функцию активации.
	2. **Функции активации:**
		1. _ReLU:_ `max(0, x)` (скрытые слои).
		2. _Сигмоида:_ `1 / (1 + e^-x)` (выход бинарной классификации).
		3. _Tanh:_ `(e^x - e^-x)/(e^x + e^-x)`.
		4. _Softmax:_ Преобразует вектор в распределение вероятностей (выход многоклассовой классификации).
13. Сверточный слой, padding, dropout
	1. **Сверточный слой:** Применяет ядра (фильтры) ко входному изображению для выделения признаков (границ, углов). маленькая матрица (например, 3×3 или 5×5), содержащая веса, которые обучаются в процессе тренировки. conv2d
	2. **Padding:** Добавление нулей по краям входного тензора, чтобы сохранить размерность после свертки.
	3. **Dropout:** Регуляризация — случайное "выключение" части нейронов во время обучения, чтобы снизить переобучение.
14. Слой субдискретизации, flatten, полносвязный слой  
	1. **Субдискретизация (Pooling):** Уменьшает пространственные размеры карт признаков (например, MaxPooling: берет максимум из окна 2x2)
	2. **Flatten:** Превращает многомерный тензор (2D карты) в одномерный вектор.
	3. **Полносвязный слой:** Каждый нейрон слоя соединен со всеми нейронами предыдущего слоя. Используется в конце сети для принятия финального решения.
15. Эпоха, батч, динамическая аугментация(ImageDataGenerator) 
	1. **Батч (Batch):** Небольшое количество примеров, подаваемых в сеть за одну итерацию.
	2. **Эпоха:** Один полный проход **всех** обучающих примеров через сеть.
	3. **Динамическая аугментация (ImageDataGenerator):** Применение случайных преобразований (повороты, масштаб, отражения) к изображениям **на лету** во время обучения. Это расширяет набор данных и борется с переобучением.
  
**Часть 4.  
16. Предобработка текста
	1. **Токенизация** (разбиение на слова), приведение к нижнему регистру, удаление стоп-слов и пунктуации, стемминг (отсечение окончаний) или лемматизация (приведение к словарной форме).
17. TF-IDF
	1. Мера важности слова в документе внутри коллекции
	2. **TF** (частота в документе): насколько часто слово встречается в данном тексте
	3. **IDF** (обратная частота в коллекции): редкость слова по всем документам
	4. `TF-IDF = TF * IDF`
18. K-Means, метод локтя
	1. **K-Means:** Итеративный алгоритм кластеризации, разбивающий данные на K кластеров, центры которых (центроиды) обновляются как среднее точек в кластере (центр масс).
	2. **Метод локтя:** Выбор оптимального K по графику суммы квадратов расстояний до центроидов. "Локоть" — точка резкого замедления снижения суммы.
19. Иерархическая кластеризация
	1. Построение дерева кластеров (дендрограммы). Бывает агломеративной (снизу вверх: каждая точка — кластер, затем сливаются) и дивизивной (сверху вниз). Не требует задания числа кластеров, его можно выбрать, "разрезая" дендрограмму.
20. DBSCAN  
	1. Кластеризация на основе плотности. Находит области с высокой плотностью точек. Может находить кластеры произвольной формы и выделять шум (точки, не вошедшие ни в один кластер). Требует задания радиуса (eps) и минимального числа точек.
``` python
from sklearn.cluster import DBSCAN
dbscan = DBSCAN(eps=1.3, min_samples=2, metric='euclidean')
```
