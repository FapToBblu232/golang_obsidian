### Семинар. Оконные функции
Для составления отчётов
*Distinct* нельзя использовать в оконных функциях

Вывести среднюю цену
```
	... avg(amount), + avg(manager), + avg(..)
	
	group by department // cube, rollout
```

```
SELECT [столбцы], НАЗВАНИЕ_ФУНКЦИИ(столбец_или_выражение) OVER (
	[PARTITION BY столбец_1, столбец_2, ... ] --Наш Groupby
	[ORDER BY столбец_3 [ASC| DESC]]
	[ROWS или RANGE between начало and конец рамка]
) AS новое_название_столбца
FROM таблица;
```

Оконная функция подтягивает значения, которые удовлетворяют нашему partition by. Т.е. берём первую строку

**4 вида:**
1) *Агрегатные*
	1) SUM
	2) MIN
	3) MAX
	4) AVG
	5) COUNT
	6) ...
2) *Ранжирующие*
   Тут используют чаще
   Часто для того, чтобы найти дубликаты
   Аргументов у них нет.
	1) *Row_Number*() - Добавляет номер строки в группе
	2) *Rank*() - Ранжирует строки. При равенстве значений даёт один ранг + пропускает (1, 2, 2, 4)
	3) *Dense_Rank*() - Ранжирует строки. При равенстве значений даёт один ранг, но без пропусков (1, 2, 2, 3)
3) *Функции смещения*
	1) *LAG*(столбец, N, значение по умолчанию) - возвращает значение из строки, отстоящей на N шагов *назад (вверх)* от текущей. +значение по умолчанию, если получили NULL
	2) *LEAD*(столбец, N, значение по умолчанию) - возвращает значение из строки, отстоящей на N шагов *вперед (вниз)* от текущей. +значение по умолчанию, если получили NULL
	   По умолчанию N=1, а Значение по умолчанию - null
	   удобно использовать `Coalesce(,)`
4) *Функции доступа к первой/последней строке*
	1) FIRST_VALUE(столбец) 
	2) LAST_VALUE(столбец)
	   По умолчанию - рамка берётся от первой до текущей строки
	   Поэтому для LAST_VALUE нужно растянуть рамку до конца

#### Агрегатные
*Задача*
Требуется для каждой сделки дополнительно вывести
- Среднюю по отделу
- Среднюю по менеджеру
- Доля этой сделки от всех сделок отдела

```
select manager, department, sale_date, amount,
AVG(amount) OVER (
	partition by department
) as Среднее по отделу,
AVG(amount) OVER (
	partition by manager
) as Среднее по менеджеру,
amount/sum(amount) OVER (
	partititon by department
) * 100 as Доля
from Sales
```
*Важно*
- Писать функции вместе, сразу.
- Ссылаться на уже вычисленную функцию нельзя даже в рамках одного запроса

#### Ранжирующие
rank + exclude 
Аргументов у них нет.

*Задача*
Какое место занимает эта сделка по отделу?
```
select manager, department, sale_date, amount,
Dense_Rank() OVER (
	partition by department
	order by amount desc)
) as Место,
from Sales
```

#### Функции смещения
*Задача*
Разницу суммы этой и предыдущей сделки у этого менеджера
```
select manager, department, sale_date, amount,
amout - LAG(ammout, 1, 0) OVER (
	partition by manager
	order by sale_date
) as Прогресс,
from Sales
```

#### Функции доступа к первой/последней строке
Сначала разберёмся с рамками
```
	Unbounded Preceding - 1ая строка группы
	N Preceding - N строк вверх от текущей
	Current row - текущая строка
	N Following - N строк вниз от текущей
	Unbounded Following - последняя строка группы
```
Если рамка выходит за границу, то там Null, агрегатные null не возьмут в оборот, кроме `Count(*)`

*Задача*
Найти самую крупную и самую первую продажу в отделе
```
select manager, department, sale_date, amount,
First_value(amount) OVER (
	partition by department
	order by sale_date
) as Первая,
Last_value(amount) OVER (
	partition by department
	order by amount -- можно наоборот, тогда и рамка не нужна, для примера сделаем так
	range between current row and unbounded following
) as Наибольшая
from Sales;
```
