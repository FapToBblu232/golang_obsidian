##### Оператор MERGE
Есть 2 таблицы A(Копия) и B(Эталонная)
Обычно данные хранятся - Эталонный + Копия
Пользователи работают с Копией. В конце дня сливаются вместе

1) Если login уже есть, то просто update по телефону
2) Если login - нет, то добавить его (insert)
w
```
begin transaction
Update TabB
Set phone = TableA.phone --для postgres
-- в MSql - (select phone from TableA where login = TabB.login)
where exists(select 1 from TabA where login = TabB.login)
```
```
Insert TabB(login, phone)
Select login, phone from TabA
where not exists(select 1 from TabB where login = TabA.login)
commit <tran (for MSQL)>; 
```

Если в результате сравнения данных нужно использовать Update, Delete, Insert по условию, то применяем MERGE

```
Megre [into] <целевая таблица> as tgt
using <таблица источник> as src(<столбец_1>, <столбец_2>,...)
on (tgt.<столбец_1> = src.<столбец_1>, ...)
when matched [and <условия ещё>]
then <оператор>
when Not Matched [and <условия ещё>]
Then <оператор>
```

Наша задача, но теперь с merge
```
Merge TabB as tgt
using TabA as src(login, phone)
on (tgt.login = src.login)
when matched
then Update Set phone = src.phone
when not Matched
then insert (login, phone) values(src.login, src.phone)
```

Целевая - всегда одна
Источник можно сформировать
```
merge Products as tgt
using (
	Select p_id, sum(qty)
	from sales join orders o
	on Sales.ord_id = o.ord_id
	and o.ord_date = current_date
	group by p_id
) as src(p_id, sum_qty)
on (tgt.p_id = src.p_id)
when matched and sum_qty >= tgt.stock
then delete
when matched
then update set stock = stock - src.sum_qty, mod_date = current_date;
```

```
Merge buyers as tgt
using (
	select b_id, Count(ord_id)
	from orders
	group by b_id
) as src(b_id, num)
on (tgt.b_id = src.b_id)
when matched and src.num > 30
then update set b_discont = 30
when matched and src.num > 20
then update set b_discont = 20
when matched and src.num > 10
then update set b_discont = 10
```
