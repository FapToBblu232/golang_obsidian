### Лекция 2. Функции, процедуры, триггеры
```
Create function <name>
(@mp fun данные [null]/[=значение][Readonly], ...) -- ()
Returns тип данны/@перем/Table
[with [encryption]/[schemadinding]]
as
Return (Select ...)
```

encryption - sysobjects + syscomments

```
cross apply = inner join для функций
outor apply = left join 
```

Не требуют on, автоматически объединяются по столбцам с одинаковыми именами.

```
Create [Or Replace] function <name>
([метод]    [имя_параметра] <тип>)
	in       необязательно
	out
	inout
Returns тип данных/переменная
as (выходные данные)
[return] (select ..)
Language SQl
with... [iscachable]/[isstrict]
       входной пар    проверка входных на null
       Результат
```

в pg можно обращаться к параметрам через $1
